# Ride Or Apologize

> Make every detour a tiny passenger diplomacy crisis.

A mobile co-ride app where drivers earn or lose apology tokens based on route choices, braking, and battery anxiety. The phone's battery level becomes how convincingly you can argue with the map.

## Features
- Live route guilt meter from GPS turns, stops, and passenger complaints
- Passenger apology prompts that scale with hard braking and detours
- Battery confidence voice mode that gets more whiny as power drops
- Trip receipt with least favorite detour and apology debt summary

## Stack
- React Native
- Mapbox
- Firebase
- Twilio

## Getting started
```
npm install; npm start; npm run ios or npm run android; add Mapbox, Firebase, and Twilio credentials to env.
```
